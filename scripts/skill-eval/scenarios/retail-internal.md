# User journey: internal spreadsheet helper at a Danish furniture retailer

1. A stock-planning analyst at a furniture retailer in Aarhus opens an
   internal web tool the IT team built.
2. The analyst pastes a spreadsheet formula that returns an error. The tool
   sends the formula text to a hosted large language model and shows a
   corrected formula with a short explanation.
3. The tool is available only to the 40 employees of the planning team on
   the company intranet, behind single sign-on.
4. It processes only formula text and error messages typed by the analyst;
   it has no access to customer, employee or supplier records.
5. Output is a suggestion the analyst can copy manually; nothing is written
   back to any system automatically.
6. A banner in the tool reads "AI-generated suggestion — verify before use."
